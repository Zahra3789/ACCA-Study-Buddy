# Zuru's voice

Drop voice clips here (`.wav` or `.ogg`) and the battles play them - no code changes needed.
The start of each file name says when it plays; add as many of each as you like and one is picked at random.

| File name starts with | Plays when |
|---|---|
| `attack` | Zuru strikes (a right answer) - short shouts: "Hah!", "Hyah!", "Ikuzo!" |
| `crit` | a critical hit (3 right in a row) - a bigger shout |
| `finish` | the finishing blow on a knocked-down enemy |
| `hurt` | Zuru takes a hit (a wrong answer) |
| `boss` | a boss appears - "Come!", "Face me!" |
| `win` | a battle or boss run is won |
| `lose` | Zuru falls |

Example: `attack_1.wav`, `attack_2.wav`, `crit_1.wav`, `finish_1.ogg`, `hurt_1.wav`.
Keep the licence of the pack you bought next to the files, and check it allows use in a game.
